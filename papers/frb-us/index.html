An open Python implementation of frb-us

Download PDF All papers

Baseline reproduces LONGBASE to 5.6e-17 (machine precision); an identical 100bp funds-rate shock matches the Fed's pyfrbus to 1.4e-8 against current pyfrbus 1.1.1 (6.0e-9 vs 1.0.0) across all 284 variables and 20 quarters.
