What a note is, and is not

A note is a reading of a data release through the models on this site. It is not investment advice, not a house view, and not a claim of forecasting skill — the models' accuracy is tracked separately and publicly, including when it is bad.

Every note states the data vintage it was written against. Because the vintage store is append-only, a note can be checked against the data as it stood when written, rather than against data revised afterwards.

Notes are not edited after publication except to correct an error, and a correction is marked as one.
