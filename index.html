Run a model

Hosted: no install, no key. Also a CLI and a Python package.

Example: a 1p rise in the basic rate

The command costs the reform with the microsimulation, then adds the OBR emulator’s GDP feedback.

Run a model CLI and Python 
$ pe-macro score --country uk \
    --reform '{"gov.hmrc.income_tax.rates.uk[0].rate":0.21}' \
    --model obr
