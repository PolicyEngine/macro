How these are measured

CPIAUCSL is an index (index 1982-84=100, seasonally adjusted), not a rate. The UK inflation topic shows two published rates because the ONS publishes them as rates; the figure above is derived from the stored index instead — 336.298 in 2026-09 against 324.245 in 2025-09 is 3.7%. One month is missing from the stored index between 2020-01 and 2026-10, which is why the comparison above is matched on the period it names rather than counted back twelve rows. The newest stored month, 2026-10, has no year-on-year rate here: the store holds no 2025-10 observation to compare it with, and none is interpolated.

Why there is no US price path

Only BoE SVAR forecasts, and it is UK-only. Both US models report a price response, and neither reports a price path:

  • FRB/US answers economic shock only; predictive validation not assessed (its baseline is illustrative, not a Fed forecast).
  • US HANK answers economic shock; it cannot answer forecasts (IRFs around a calibrated steady state, not a forecaster). Predictive validation not applicable: it makes no predictive claims.
  • us-hank outputs GDP, consumption, investment, inflation, real rate as quarterly impulse responses, typically 5 years around a calibrated steady state, with uncertainty none quantified; deterministic linear IRFs.
  • Neither model is scored against an inflation outturn anywhere on this site, because neither produces one to score.
No core CPI

There is no US core series in the store, so this page shows headline CPI only. Adding one means adding CPILFESL to the FRED table in data/fetch.py and letting vintages accumulate.

Run it yourselfThe commands and MCP tools behind this page.

The price response to a policy surprise, in both models. The FRB/US run is a reviewed add-factor shock in model units; the HANK run is a first-order impulse response around the paper's calibration. 

pe-macro frbus-shock --var rffintay_aerr --shock 1.0 --horizon 20   # price response to a 1pp policy surprise
pe-macro hank-summary   # shock catalogue, units and scope limits
pe-macro hank-shock --kind monetary --size -0.0025 --persistence 0.61   # a 25bp-per-quarter (about 100bp annualised) easing, quarterly IRF

Over MCP the same two models are frbus_shock and hank_shock, their metadata and scope limits are frbus_summary and hank_summary, and get_model_status returns the limitations quoted above as structured data rather than prose. recommend_model returns an explicit warning rather than a guess when no model supports a request.
