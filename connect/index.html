Use the models

One hosted MCP server, one CLI and one Python package over the same tools. Hosted use needs no install, no account and no API key.

Three ways to run them

MCP first, then the CLI, then Python; the CLI and Python also run the local-only members.

1Hosted: connect an AI client over MCP

Add one URL to an MCP client, then ask in plain language.

  1. Copy the server URL

    https://policyengine--policyengine-macro-mcp-serve.modal.run/mcp

  2. Add it to your client

    On claude.ai or in the Claude Desktop app, open Settings → Connectors, choose “Add custom connector”, and paste the URL.

    In a terminal, with Claude Code:

    claude mcp add --transport http policyengine-macro https://policyengine--policyengine-macro-mcp-serve.modal.run/mcp

    On an eligible ChatGPT web plan, enable Developer mode in Settings → Apps → Advanced Settings, create a custom app, and paste the URL. Workspace admins may need to grant access.

    For Codex CLI, register the same MCP endpoint:

    codex mcp add policyengine-macro --url https://policyengine--policyengine-macro-mcp-serve.modal.run/mcp

    Add the URL as a remote (HTTP) MCP server — Gemini CLI, Cursor, VS Code, Windsurf, Mistral Le Chat, and any other MCP-capable client. Look for “MCP servers” or “connectors” in its settings.

    For the Gemini CLI, register the same MCP endpoint:

    gemini mcp add --transport http policyengine-macro https://policyengine--policyengine-macro-mcp-serve.modal.run/mcp

  3. Ask a policy question

    • How much tax would a single 35-year-old earning $50,000 pay in Los Angeles County, California?calculate_household
    • Score raising the UK basic rate of income tax to 21p.start_job · score_reform
    • What is the UK GDP and inflation outlook for the next four quarters?forecast_ukboe-svar: no forecast skill against a drifting random walk
    • What happens to US GDP and unemployment if the Fed raises rates by 100 basis points?frbus_shock
    • How does a 25 basis point cut in the quarterly US policy rate (about 100bp annualised) change consumption across wealth quartiles?hank_shock

    A reform score outlasts one HTTP request, so the client runs it as a job (start_job, then get_job_result until it is done); the tool descriptions tell it to. See limits.

Run the same server on your own machine

To run the same server on your own machine over stdio (no request ceiling; local-only tools run where their packages are installed), install the package as in step 2, then:

claude mcp add policyengine-macro -- python -m policyengine_macro.mcp_server

3Python: hosted or local

Call the hosted server from a script with the MCP client, or import the adapters and run locally.

hosted.py · pip install "mcp>=1,<2"
import asyncio, json
from mcp import ClientSession
from mcp.client.streamable_http import streamablehttp_client

URL = "https://policyengine--policyengine-macro-mcp-serve.modal.run/mcp"

async def call(tool, args=None):
    async with streamablehttp_client(URL, timeout=300) as (read, write, _):
        async with ClientSession(read, write) as session:
            await session.initialize()
            res = await session.call_tool(tool, args or {})
    if res.isError:  # a failed tool or job returns plain text, not JSON
        raise RuntimeError(res.content[0].text)
    return json.loads(res.content[0].text)

async def run_job(tool, args):
    """Slow tools: start a job, then poll until it is done."""
    job = await call("start_job", {"tool": tool, "arguments": args})
    while True:
        r = await call("get_job_result", {"job_id": job["job_id"], "wait_seconds": 30})
        if r["status"] == "done":
            return r["result"]

forecast = asyncio.run(call("forecast_uk", {"horizons": 4}))
score = asyncio.run(run_job("score_reform", {
    "country": "uk", "model": "obr",
    "reform": {"gov.hmrc.income_tax.rates.uk[0].rate": 0.21},
}))

Set up one model

Each model’s own package, pins and reproduction steps are on its Code tab.

  • PolicyEngine microsimulationhostedTaxes, benefits, net income and reform effects, household by household — PolicyEngine’s own engine, and the usual starting point. It cannot answer GDP, inflation, interest rates or macro feedback; the macro models below add those.
  • OBR emulatorhostedTrace tax and spending changes against the OBR baseline.
  • BoE SVARhostedForecast GDP and inflation or explain what moved them.
  • FRB/UShostedRun FRB/US impulse responses under a chosen policy rule.
  • US HANKhostedRun stylized HANK shocks with MPC and hand-to-mouth detail.
  • OG-UKlocalModel work, saving, capital, and public finances over decades.
  • OG-UK + microsimulation (dynamic scoring setup)local onlyExperimental, UK only: an OG-UK steady-state solve feeds long-run wage changes back into a second microsimulation run. Local only, and until OG-UK#68 the solve needs its own environment — run pe-macro og-score --reform '{"gov.hmrc.income_tax.rates.uk[0].rate":0.21}' --json > og.json there, then pe-macro dynamic-score --reform '{"gov.hmrc.income_tax.rates.uk[0].rate":0.21}' --og-payload og.json — both steps need the same --reform.
  • DEFINE-UKlocal onlyExperimental: pip install git+https://github.com/PolicyEngine/define-uk-model fetches the pinned upstream at runtime. That upstream is unlicensed and is never hosted, so scenario deltas come from a cached local run — a fresh one needs local R.

Access, limits and cold starts

No account or key; slow calls run as jobs.

Auth
None. No account, no API key. Some clients gate custom connectors by plan.
Ceiling
The hosting transport abandons any HTTP request after 150 seconds. start_job hands a slow call to a worker with a 30-minute budget and returns a job id; poll get_job_result.
Concurrency
At most three containers at once, as a spend cap; the server scales to zero when idle.
Cold start
A container stays warm for five minutes after the last request. In a fresh one the first PolicyEngine call pays a ~20 s model import, and the first UK forecast a couple of minutes of estimation. Warm calls are fast.
UK microdata
Only a local UK population or reform score needs HUGGING_FACE_TOKEN (private policyengine-uk-data-private). Hosted calls need nothing.
Local only
model='og', dynamic_reform_impact (tens of minutes) and the DEFINE-UK scenarios (unlicensed upstream). Called hosted they return run instructions or an import error, not results: use the CLI or local Python.
Results
Every score_reform result carries a common score block: model class, horizon, provenance, units and time basis, assumptions, caveats and a comparability label. Results from different model classes are complementary, not to be averaged or ranked.
About jobs and polling

get_job_result blocks at most 60 seconds per call; keep polls short. A poll that errors is not a failed job: call again with the same id. Job names are the adapter names: score_reform, obr_shock, frbus_shock, hank_shock, pe_population_impact, dynamic_population_reform_impact.
