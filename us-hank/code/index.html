Ask the server, or install it

Four steps from a hosted call to the local Python API; the commands sit in the panel beside each step. For every other model and client, see Use.

1

Ask the hosted server

Quickest is the hosted MCP server: hank_shock runs a stylized shock, optionally with the distributional block; hank_summary lists shock kinds, units, variants and scope limits, instantly, with no solve; hank_shock_incidence passes the wage and labor responses to the US microsimulation (the join).

About this step

Three MCP tools

The first call per variant is slow; the model card gives the timings.

2

Or use the CLI

Same two calls

The same two operations on the command line: hank-summary to see what the model accepts, hank-shock to run one — here a 25bp monetary easing with the distributional block on.

Pe-macro CLI

pe-macro hank-summary
pe-macro hank-shock --kind monetary --size -0.0025 --persistence 0.6 --distribution
3

Know the units and variants

monetary: level change in the quarterly policy rate (−0.0025 = a 25bp easing); fiscal_spending: level change in G (steady-state output is 1, so 0.01 = 1% of GDP); productivity: level change in TFP.

About this step

Units differ per kind

Two variants

variant selects the paper's two_asset model (the default) or a fast one_asset textbook variant — no capital, so no investment response, and monetary/productivity shocks only.

4

Install and script it

Beyond the hosted surface, install the package and use the Python API directly: solve the steady state once, solve the Jacobian once, then draw impulse responses and distributional summaries instantly.

Install

pip install git+https://github.com/PolicyEngine/us-hank-model

Python api

from us_hank import model, distributional

ss = model.solve_steady_state()          # ~13s, cached
G = model.solve_jacobian(ss, T=300)      # ~5s, cached

irf = model.shock("monetary", size=-0.0025, persistence=0.6, ss=ss, G_jac=G)
print(irf["Y"][:8])                      # output, % deviation from steady state
print(distributional.summary(ss))        # MPCs by quartile, hand-to-mouth share
