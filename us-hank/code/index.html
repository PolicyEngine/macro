Ask the server, or install it

Four steps, from a hosted call to the local Python API.

1

Ask the hosted server

The hosted MCP server has three tools: hank_shock runs a stylised shock, optionally with the distributional block; hank_summary lists shock kinds, units, variants and scope limits, with no solve; hank_shock_incidence passes the wage and labour responses to the US microsimulation (the join).

About this stepnotes

The first call per variant is slow; the model card gives the timings.

2

Or use the CLI

hank-summary shows what the model accepts; hank-shock runs one shock, here an easing shock of −0.0025 to the Taylor-rule intercept (ρ 0.61) with the distributional block on.

pe-macro hank-summary
pe-macro hank-shock --kind monetary --size -0.0025 --persistence 0.61 --distribution
3

Know the units and variants

monetary: level change in the quarterly Taylor-rule intercept (−0.0025 is 25bp per quarter, about 100bp annualised; the quarterly policy rate itself falls only about 13bp on impact at ρ 0.61, because the rule responds to the inflation the cut causes); fiscal_spending: level change in G (steady-state output is 1, so 0.01 = 1% of GDP); productivity: level change in TFP (steady-state TFP is 0.468, so 0.01 is a 2.14% rise, not 1%).

About this stepnotes

variant selects the paper's two_asset model (the default) or a fast one_asset textbook variant: no capital, so no investment response, and monetary and productivity shocks only.

4

Install and script it

Install the package, solve the steady state and the Jacobian once, then draw impulse responses and distributional summaries instantly.

pip install git+https://github.com/PolicyEngine/us-hank-model
from us_hank import model, distributional

ss = model.solve_steady_state()          # a few seconds, cached
G = model.solve_jacobian(ss, T=300)      # a few seconds, cached

irf = model.shock("monetary", size=-0.0025, persistence=0.61, ss=ss, G_jac=G)
print(irf["Y"][:8])                      # output, % deviation from steady state
print(distributional.summary(ss))        # MPCs by quartile, hand-to-mouth share
