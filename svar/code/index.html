Estimate, identify, decompose

Four routes into the model, hosted to local: MCP tools, CLI mirrors, Python, and the runner scripts that rebuild the paper’s outputs.

1

Hosted MCP tools

The quickest route is the hosted MCP server.

More detail

Four tools reach this model: forecast_uk (YoY GDP-growth and CPI-inflation fan charts with 68%/90% bands), latest_shocks (posterior sign probabilities of each identified shock in the latest quarter), model_summary (headline replication results — instant, no estimation), and the experimental svar_inflation_incidence (the CPI gap priced through benefit uprating in the microsimulation).

Hosted tools

Forecast
forecast_uk(horizons=12, draws=2000)
Shocks
latest_shocks(draws=2000)
Headlines
model_summary(), instant
Incidence
svar_inflation_incidence(year=2027), experimental
About this step

No install, no credentials

Draws and runtime

The first call estimates the model, a couple of minutes cold; results are cached in-process. The default 2,000 draws yield about 135 accepted (ESS about 65); about 3,500 reach ESS 100. Every response carries a warnings list when inference is weak.

2

CLI mirrors

Same tools from the terminal

The CLI mirrors the four MCP tools one for one. Same outputs, no MCP client required.

CLI commands

pe-macro forecast --horizons 12 --draws 2000   # fan charts
pe-macro shocks                                # latest-quarter shocks
pe-macro summary                               # replication headlines
pe-macro svar-inflation-incidence --year 2027  # experimental
3

Install locally

The package installs straight from GitHub with the prepared quarterly dataset inside, so boe_var.data.load_data() works immediately.

Install

pip install git+https://github.com/PolicyEngine/boe-var-model
from policyengine_macro import svar_forecast, svar_latest_shocks

fc = svar_forecast(horizons=12, draws=2000)   # median + 68%/90% bands
shocks = svar_latest_shocks(draws=2000)
About this step

One pip install

All inputs are public

Every input series is public: ONS (CPI, CPI energy, real GDP), Bank of England (Bank Rate, sterling ERI), and FRED (oil, exchange rates, world components).

Or through the suite, from Python

The same calls as the hosted tools, returning dicts: install the suite (pip install "policyengine-macro[models] @ git+https://github.com/PolicyEngine/macro#subdirectory=integration") and import them.

4

Development runner scripts

The runner scripts are for development — clone the repository to rebuild the dataset or regenerate the paper outputs.

Runner scripts

python scripts/download_data.py     # reassemble the public data

# the paper's core outputs: IRFs, FEVDs, shocks, historical decompositions
python scripts/run_replication.py

# the forecasting toolkit: fan charts, latest-quarter shock distributions,
# composite IRFs, and the forecast-revision decomposition
python scripts/run_forecast_revision.py
About this step

Clone to rebuild everything

What lands where

outputs land in results/ — the replication figures (fig2–fig6), the forecast figures (fig1, fig7–fig9), and two summary reports. runtime scales with draw count; the importance weights are the expensive part — one numerical Jacobian per accepted draw.
