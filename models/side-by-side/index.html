Method, data, connection, scope and runtime, model by model

PolicyEngine microsimulation pe-microsim

Method
Static tax-benefit microsimulation — direct rule evaluation, no behavioural response
Data vintage
UK & US statute; enhanced FRS 2023–24 microdata for UK population runs
Microsim connection
Is the microsimulation — every bridge starts or ends here
Reform scoring
Yes — a PolicyEngine parameter + a new value, applied directly to households
Out of scope
GDP, inflation, interest rates, or macro feedback
Run surface
Hosted
Typical runtime
Sub-second per household; minutes for population runs

OBR emulator obr-macro

Method
Structural macroeconometric emulator — Gauss–Seidel over 372 equations per quarter
Data vintage
OBR Economic and Fiscal Outlook, March 2026
Microsim connection
Static costing in, macro feedback out — score_reform via HHDI_ADDFACTOR
Reform scoring
Yes — shocks to exogenous model variables; static-costing bridge from PolicyEngine reforms
Out of scope
Arbitrary reform incidence; borrowing; capital spending (CGIPS is dead) and corporation-tax magnitudes (TCPRO converges slowly)
Run surface
Hosted (CLI, MCP, Python API)
Typical runtime
Seconds to minutes per scenario

BoE SVAR boe-svar

Method
Bayesian structural VAR — posterior sampling with zero and sign restrictions
Data vintage
ONS, BoE and FRED — estimated through 2025Q1, conditioned to the 2026Q1 edge
Microsim connection
CPI path → benefit-uprating incidence (svar_inflation_incidence, experimental)
Reform scoring
No — the baseline/conditioning member: it reads the economy reforms are scored against
Out of scope
The causal effect of a specific statutory reform
Run surface
Hosted (CLI, MCP, Python API)
Typical runtime
Minutes per full estimation + identification run

FRB/US frb-us

Method
Large-scale macroeconometric model — 284 equations solved under VAR expectations
Data vintage
The Fed's model.xml and LONGBASE database, April 2026
Microsim connection
Wage/hours path → employment-income incidence (frbus_shock_incidence, experimental)
Reform scoring
No — shock experiments only; no reform bridge, so score_reform refuses model="frbus"
Out of scope
PolicyEngine reform effects, anticipated-policy paths, or MCE scenarios
Run surface
Hosted (CLI, MCP, Python API) — raw shocks only
Typical runtime
Seconds to minutes per simulation

US HANK us-hank

Method
Two-asset HANK (Auclert et al. 2021) — first-order sequence-space impulse responses
Data vintage
The published Econometrica 2021 calibration; no data vintage
Microsim connection
Wage/labor IRFs → employment-income incidence (hank_shock_incidence, experimental)
Reform scoring
No — stylized shocks only; the labor tax is endogenous, so score_reform refuses model="hank"
Out of scope
Forecasts, detailed tax reforms, or nonlinear/state-dependent dynamics
Run surface
Hosted (CLI, MCP, Python API) — stylized shocks only
Typical runtime
About 10 seconds cold on a laptop (cached); instant warm

OG-UK psl-og

Method
Dynamic general equilibrium (OLG) — steady-state root-find and transition-path iteration
Data vintage
ONS, OBR and BoE aggregates as calibration targets; OG-UK 0.3.2
Microsim connection
Two-way: statute in via PE tax functions; long-run changes back into a second microsim run (og+microsim)
Reform scoring
Yes — a PolicyEngine policy translated into estimated tax functions
Out of scope
A short-run forecast or independently validated reform effect
Run surface
Local only
Typical runtime
Many minutes per steady-state solve (two per score; not timed); transition paths far longer

DEFINE-UK define-uk

Method
Ecological stock-flow consistent (E-SFC) — upstream R code run unmodified at a pinned commit
Data vintage
DEFINE-UK 1.1, April 2026, at pinned commit 846081a
Microsim connection
Scenario income deltas → employment-income incidence (define_scenario_incidence, experimental; hosted via define_payload)
Reform scoring
No — no reform bridge; score_reform will not accept it
Out of scope
Levels, forecasts, reform scoring; microsimulation incidence (planned, post-validation)
Run surface
Local CLI (pe-macro define-scenario); hosted MCP tools return run instructions
Typical runtime
Instant from the cached pinned run; a fresh upstream run takes tens of minutes in R 4.3
