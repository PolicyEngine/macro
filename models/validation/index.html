How each model is checked

Four classes of check, one verdict per model.

Is any model validated? Not as a forecaster. None of the seven verdicts below claims forecast skill; the strongest checks are exact household rule arithmetic and replication of a published model or paper.

The seven models support different kinds of check, grouped below into four classes with one verdict each.

Checked against implemented legislation
The rules are code, checked rule by rule; a household answer can be verified by hand.
Replication with a published anchor
Reproduces a published model or paper. An imposed match is an anchor, not a validation.
Calibrated counterfactual
Targets are met by construction, so there is no ground truth to test against.
Partial replication
One block replicates a published table; the rest is checked only against the published design (design-gated).
