OG-UK OLG · UK · local · long-run steady state

OG-UK

Shows where the UK economy settles under a tax reform, and the year-by-year path there.

Overview Methodology Validation Code Paper

Calibrated Calibrated, with no outcome benchmark: ONS and OBR aggregates are targets met by construction, and the nearest external benchmark, OBR Working Paper 22 Table 5.1, has not yet been run. How far to trust it →

Good for

  • Long-run effects of a tax reform on GDP, work, saving and capital
  • Year-by-year transition paths, and eight industry sectors
  • Wages back to the microsimulation for a dynamic score

Not for

  • Forecasts: results are model-consistent magnitudes and signs, not predictions (why)
  • Quarterly dynamics: OBR emulator
  • Who gains and loses this year: PolicyEngine microsimulation

What it returns

A stylised reform, not announced policy: reform against baseline from the committed transition path.

With the microsimulation

Both directions: statute in, long-run wages back.

Reform → OG-UKlong-run wages → PolicyEngine microsimulationsecond run → Dynamic score

The reform runs through the microsimulation, OG-UK returns long-run wages, and a second microsimulation run gives the dynamic score (every join in the suite).

Model-consistent magnitudes, not forecasts: there is no ground truth to score them against, and the committed run predates OG-UK’s July 2026 labour-tax-rate fix (limits).
