What stock-flow consistency means

DEFINE-UK is an ecological stock-flow consistent (E-SFC) model: DEFINE-UK 1.1, April 2026, by George and Dafermos (SOAS), building on the DEFINE model of Dafermos, Nikolaidi and Galanis (define-model.org).

Accounting before theory

Stock-flow consistency is an accounting discipline before it is an economic theory.

  • Every monetary flow leaves one sector's account and enters another's.
  • Flows include wages, taxes, interest, dividends and lending.
  • So a transactions matrix sums to zero in every row and column.
  • Every flow accumulates into a stock, so sector balance sheets close each period.
  • Nothing appears from nowhere and nothing leaks out.
  • In the cached upstream outputs that holds in every quarter, with one exception.
  • The exception is three quarters of two fossil-fuel-ban scenarios (limits).

The ecological coupling

The ecological part couples that closed monetary accounting to an emissions and energy block, so climate policy and the financial system move together in one system. An emissions block splits electricity from non-electricity emissions; the components sum exactly to the total in the model's output.

The sectors

The balance-sheet matrix (manual §2.2 Table 2) mirrors the transactions matrix: every financial instrument row sums to zero — one sector's asset is another's liability — and each sector's column sums to its net worth.

Calibration

The model is calibrated to UK national accounting data (ONS Blue Book / UKEA), with the manual's §5 tables giving parameters and initial values.

The housing and power blocks

Two structural blocks distinguish DEFINE-UK from a generic E-SFC model.

The two UK blocksPower · What version 1.1 added

The housing block tracks the UK housing stock by energy efficiency, so retrofit policy — subsidies and regulation — changes household energy demand and emissions through the stock, not through a reduced-form elasticity.

Power

The power-sector block carries separate fossil and renewable capital stocks.

  • Government renewable investment triggers when non-fossil capacity falls short of a utilisation threshold.
  • The threshold is set relative to electricity demand.
  • Regulation policies (new in version 1.1) can directly depreciate fossil capital.
  • Stranded assets become an explicit balance-sheet event.
  • The financial institutions that hold the claims feel it.

What version 1.1 added

Version 1.1 (April 2026) added regulatory policies, limited forward-looking behaviour to policy announcements, direct government ownership of non-fossil power capital, and a green sovereign bond instrument.

Demand-led closure and multipliers

DEFINE-UK is closed demand-led: output adjusts to aggregate demand rather than being pinned to a supply-side potential path.

Closure and multipliers
Closure

The closure

Demand-led is the standard post-Keynesian SFC closure, and it has a direct, observable consequence — fiscal expansions are not crowded out by an assumed return to potential, so long-horizon fiscal multipliers come out larger than in supply-constrained models like the OBR emulator.

Measured, not asserted

  • The cumulative green-public-investment multiplier is our own computation: 2.25 per pound of the power-sector spending the policy sets, nominal, from the 2027 policy start to 2040.
  • It is back-loaded, so it sits below published short-horizon multipliers at their horizons (the multiplier by horizon).
  • It includes a Baseline/policy parameter mismatch (limits).

No numeric scenario results are published for v1.1.

  • So the switch sets themselves are part of our validation surface.
  • A design gate checks 8 of the cached scenarios against their published descriptions.
  • Each must toggle exactly the claimed policy switches — no more, no fewer.

The constraint

The missing licence shapes the whole architecture.

  • The adapter fetches the upstream R code at commit 846081a at run time.
  • It executes that code unmodified, in R.
  • Nothing upstream is vendored, redistributed, or hosted.
  • A full notebook run is cached: R 4.3.0, 151 output files, all four scenario blocks.
  • The scenario surface reads from that pinned run, not a per-query model re-run.

Deltas only, local only

The command-line tools return scenario deltas, never levels.

  • pe-macro define-scenarios and pe-macro define-scenario return annualised scenario-minus-baseline delta paths only.
  • Results are framed with mandatory caveats.
  • Never levels: the baseline's calibration gap to ONS/DESNZ/OBR actuals is computed and material.
  • The hosted MCP tools return run instructions instead of results.
  • That is because the unlicensed upstream is never hosted.
  • score_reform will not accept this model.

The clean-room path to hosting

The path to hosting is a clean-room Python reimplementation of the published Model Manual.

  • This is the same adapted-model approach as the OBR emulator.
  • The manual is the specification; the upstream run is a numerical oracle only.
  • Its outputs are compared against ours.
  • Its source code is never read to write equations.
  • Every equation must reference the manual section and equation number it implements.
  • Five milestones run from the accounting core to the full policy scenarios.
  • Gate results are on Validation; progress is on the Use it tab.
