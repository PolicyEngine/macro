DEFINE-UK

Scores how a UK climate-policy mix moves output, emissions, unemployment and consumption, as deltas against the current-policies baseline.

Overview Methodology Validation Use it
Deltas only, never levels. Evidence →
Why

Deltas only, never levels: the baseline sits far from official outturns, and no numeric v1.1 scenario results are published, so the replication gates are the ceiling.

Good for

  • Climate-policy scenarios from the papers’ published switches
  • Output, emissions, unemployment, consumption as deltas from the S1 baseline
  • Scenario income deltas for the incidence bridge (experimental)

Not for

  • Levels or forecasts (limits)
  • Results from the hosted tools: they return run instructions only
  • 2023–26 deltas as policy effects: one coefficient differs between runs (limits)

What it returns

Scenario minus baseline, run locally against the upstream model at a pinned commit.

Against
the S1 current-policies baseline
Scenarios
the papers’ published policy switches

The path to hosting is a clean-room reimplementation of the published manual. The green-public-investment scenario is checked on Validation.

With the microsimulation

Connected experimentally: deltas in, incidence out.

DEFINE-UKscenario deltas → PolicyEngine microsimulationUK earnings overlay → Who gains and loses

define_scenario_incidence turns a scenario’s household income deltas into a pre-tax earnings overlay on the UK population. Only the numbers travel, never the upstream code (every join in the suite).

Two checks do not pass: baseline emissions run below the published table, and the green-public-investment multiplier runs high (emissions, multiplier).
