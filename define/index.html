DEFINE-UK ecological stock-flow

DEFINE-UK

Scores how a UK climate-policy mix moves output, emissions, unemployment and consumption, as deltas against the current-policies baseline.

  • UK
  • Partial replication
  • Runs locally
  • Annual, 2023–2040; default to 2037
Overview Methodology Validation Use it
Deltas only, never levels. Evidence → The baseline sits far from official outturns. No numeric v1.1 scenario results are published, so the replication gates are the ceiling.

Good for

  • Climate-policy scenarios from the papers’ published switches
  • Output, emissions, unemployment, consumption as deltas from the S1 baseline
  • Scenario income deltas for the incidence bridge (experimental)

Not for

  • Levels or forecasts (limits)
  • Results from the hosted tools: they return run instructions only
  • 2023–26 deltas as policy effects: one coefficient differs between runs (why)

A worked example

Green public investment (green_public_investment), minus the current-policies baseline, from the cached pinned run (upstream commit 846081a).

Extra public spending on green power, financed with green bonds

About £15–16bn a year in 2027–31, tapering to 2035: £98bn gross, £91bn net of a small claw-back after 2035.

Real GDP, 2035+0.91%peak +0.92% in 2034; real GDP flat in 2027–28
Emissions, 2035−54 MtMtCO2e a year (−18.4%)
Unemployment, 2035−0.22pppercentage points
Real consumption, 2035+1.01%households

Effects on public debt and interest costs are not among the served outputs, so the fiscal side of the green-bond financing is not shown here.

  • By 2040 (full run) the GDP gain fades to +0.25% and the emissions cut to 23 MtCO2e a year
  • The gain is back-loaded: nominal GDP rises about £0.5 per £ spent in 2027 while real GDP stays flat, then real GDP peaks in 2034 as spending winds down (the 2.30 multiplier is nominal; 3.26 in real terms) (multiplier)
  • In 2035, 46 of the 54 Mt come from outside the power sector (2030: 23 of 49): electricity becomes much cheaper (−52% in 2030), which moves other sectors off fossil fuels; this channel is read from the outputs, not traced equation by equation (limits)

Read with care. Every delta includes a parameter mismatch between the baseline and policy runs, about −0.16% of GDP (limits). No published v1.1 result exists to check these against.

Several checks do not pass (limits):

  • Baseline emissions run below the manual’s table and above DESNZ actuals
  • Baseline growth is far above outturn
  • Two scenarios are refused as not stock-flow consistent
  • Subsidy scenarios lower GDP for several years, so far unexplained (detail)

Run it

The worked example above, three ways, after a one-off local R run. Defaults return 2023–2037; 2023–26 is the parameter mismatch alone.

Using DEFINE-UK, run the green public investment scenario and show real GDP, emissions and unemployment as deltas from baseline, year by year.DEFINE-UK is local-only: the hosted tools (define_scenario) return run instructions, never results. Install the adapter, then run it locally or through a local MCP server. Connect

pip install git+https://github.com/PolicyEngine/define-uk-model
pe-macro define-scenario green_public_investment
from define_uk import scenarios
r = scenarios.run_scenario("green_public_investment")
print(r["years"], r["variables"]["GDP_R"]["delta_pct"])
