Discover hosted, run locally

The upstream is unlicensed, so the hosted server lists scenarios and bridges results but never runs the model: you produce the deltas on your machine.

1

Hosted MCP tools

Three tools on the hosted MCP server reach this model. None of them runs it.

More detailnotes

define_list_scenarios returns the curated scenario set; define_scenario returns local run instructions; and define_scenario_incidence (experimental) takes a define_payload of locally produced deltas and turns them into a pre-tax earnings overlay on PolicyEngine's UK population.

About this stepnotes

What each scenario represents is on the overview; the gates behind the numbers are on the validation page.

2

Install locally

The adapter installs from GitHub. Nothing upstream is vendored: at runtime it fetches DEFINE-model/DEFINE_UK_1.1 at pinned commit 846081a and runs the published notebook unmodified.

pip install git+https://github.com/PolicyEngine/define-uk-model
About this stepnotes

Install

A fresh full run needs local R with the notebook's packages; after that, scenario deltas are instant from the cached pinned run.

3

CLI scenario runs

List the curated scenarios, then run one locally for its deltas against baseline: real GDP, emissions, unemployment, real consumption. Deltas only, never levels.

pe-macro define-scenarios              # list the curated set
pe-macro define-scenario <name>        # scenario deltas vs baseline

Development

More detailnotes

Hermetic artifact checks always run, and the oracle comparisons against the pinned upstream run execute wherever a local cache exists. In CI they must skip, because a passing oracle test there would mean the unlicensed upstream was fetched.

About this stepnotes

A clean-room Python reimplementation of the published Model Manual v1.1 is the route to a hostable model — protocol and milestones in REIMPLEMENTATION.md, upstream code used only as a numerical oracle.

Every printed equation of the manual (§3.1–§3.4.7) is now registered and the whole model solves quarter by quarter. It does not reproduce the upstream run: baseline GDP falls up to 44% below it by 2040 and its green-investment multiplier is 1.52 against the upstream’s full-run 2.30, so milestone 2 is not passed and nothing here is hostable yet; the hosted tools continue to return run instructions.

Reimplementing from the manual is also what surfaces its gaps, and thirteen are now pinned by tests as machine-readable gap records rather than absorbed into a tolerance, with more written up in the reimplementation notes — a net-lending residual the manual itself says “should equal 0”, identities that fail at the manual's own initial values, and symbols the equations use that the parameter tables never list. The largest is a blocker: §3.3.2 as published cannot be simulated forward. Six parameters it uses are absent from Table 5, and two variables are never defined anywhere in the manual, so credit rationing collapses to a constant and desired power-sector investment turns negative. That is the section the climate-policy scenarios run through, and it is recorded in full for the authors.
